## Logo

The pmndrs logo, in four states, as four SVG files. Download a variant below,
or install all four in a shadcn project:

```sh
npx shadcn@latest add pmndrs/design-system/logo#v0.9.0
```

That writes them to `public/pmndrs/` at the root of your project, under the names below.

Every file is 600×600 and paints its own black square background: there is no transparent
variant yet.

### Usage

Once installed (or copied into your app's `public/pmndrs/` by hand), each file is an image URL.
Both animations are CSS inside the SVG, so a plain `<img>` plays them, and so does `next/image`
with `unoptimized`:

```html
<img src="/pmndrs/logo_loading.svg" width="48" height="48" alt="Loading" />
```
