# Poimandres component Storybook

Explore the examples and APIs of components supported by the pmndrs design system
in one place.

## How composition works

Each versioned section in the sidebar comes from a Storybook published by the
repository that owns those components. Composition brings its stories into this
navigation and displays their original previews. Examples stay maintained in their
source repository; they are not copied or recreated here.

Expand a section, then choose **Docs** for a component's API or a story for an
example. Controls, when available, let you try different props.

The sidebar selects the components supported by the DS registry catalog. Remote
search results can include other components from the source Storybook; appearing
in search does not mean a component is supported.

## Which version am I seeing?

The version in the section's name is the release pinned by the DS catalog. Its
stories come from a fixed published build of that release, rather than the source
repository's latest branch. New upstream stories appear here when the catalog and
its Storybook reference are updated together.
