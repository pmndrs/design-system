<Intro>
  Two families of motion utilities: `duration-*` sets how long a transition runs, and `ease-*`
  the curve it follows. A transition that names neither runs on one default for each.
</Intro>

> [!NOTE]
> Inherited from Tailwind v4 defaults, not yet a pmndrs decision. See [Tailwind's transition-duration docs](https://tailwindcss.com/docs/transition-duration).

## Defaults

A `transition-*` utility (`transition`, `transition-colors`, `transition-transform`…) without a
`duration-*` or an `ease-*` runs on these two theme variables:

| Variable | Value |
| --- | --- |
| `--default-transition-duration` | <code>{transitions['--default-transition-duration'].value}</code> |
| `--default-transition-timing-function` | <code>{transitions['--default-transition-timing-function'].value}</code> |

The default curve is the one `ease-in-out` sets.

## Duration

`duration-*` sets `transition-duration` in milliseconds: `duration-300` is `300ms`. No theme
variable stands behind it, so any number works, not only the steps below: `duration-250` is
`250ms`. Use brackets for another unit (`duration-[2s]`).

| Utility | Value |
| --- | --- |
| `duration-0` | <code>{durations['duration-0'].value}</code> |
| `duration-75` | <code>{durations['duration-75'].value}</code> |
| `duration-100` | <code>{durations['duration-100'].value}</code> |
| `duration-150` | <code>{durations['duration-150'].value}</code> |
| `duration-200` | <code>{durations['duration-200'].value}</code> |
| `duration-300` | <code>{durations['duration-300'].value}</code> |
| `duration-500` | <code>{durations['duration-500'].value}</code> |
| `duration-700` | <code>{durations['duration-700'].value}</code> |
| `duration-1000` | <code>{durations['duration-1000'].value}</code> |

Hover the panel to run every step at once, on the default curve:

<div className="group grid! gap-3 rounded-lg bg-surface-container-low p-6">
  {['duration-0', 'duration-75', 'duration-100', 'duration-150', 'duration-200', 'duration-300', 'duration-500', 'duration-700', 'duration-1000'].map((duration) => (
    <div key={duration} className="grid! grid-cols-[8rem_1fr] items-center gap-4">
      <code className="text-sm">{duration}</code>
      <div className={`h-3 origin-left scale-x-0 rounded-full bg-primary transition-transform group-hover:scale-x-100 motion-reduce:transition-none ${duration}`} />
    </div>
  ))}
</div>

## Easing

`ease-*` sets `transition-timing-function`, from the `--ease-*` theme variables. See
[Tailwind's transition-timing-function docs](https://tailwindcss.com/docs/transition-timing-function).

| Utility | Variable | Value |
| --- | --- | --- |
| `ease-linear` | none | <code>{easings['ease-linear'].value}</code> |
| `ease-in` | `--ease-in` | <code>{easings['ease-in'].value}</code> |
| `ease-out` | `--ease-out` | <code>{easings['ease-out'].value}</code> |
| `ease-in-out` | `--ease-in-out` | <code>{easings['ease-in-out'].value}</code> |

`ease-in` starts slow, so it suits an element leaving the screen. `ease-out` ends slow, so it
suits an element arriving. `ease-in-out` suits an element that moves from one place to another.

Hover the panel to run every curve at once, over `duration-1000`:

<div className="group grid! gap-3 rounded-lg bg-surface-container-low p-6">
  {['ease-linear', 'ease-in', 'ease-out', 'ease-in-out'].map((ease) => (
    <div key={ease} className="grid! grid-cols-[8rem_1fr] items-center gap-4">
      <code className="text-sm">{ease}</code>
      <div className={`h-3 origin-left scale-x-0 rounded-full bg-primary transition-transform duration-1000 group-hover:scale-x-100 motion-reduce:transition-none ${ease}`} />
    </div>
  ))}
</div>

## Reduced motion

Prefix a utility with `motion-reduce:` to drop a transition for people who ask their system for
less motion: `motion-reduce:transition-none`. The previews above do.
