<Intro>
  Two font families: Inter for everything, Inconsolata for code. Sizes come from Tailwind's
  `text-*` scale, and headings, paragraphs and lists follow shadcn's class recipe.
</Intro>

## Font family

| Role | Family | Utility | Variable |
| --- | --- | --- | --- |
| Sans | {fonts['font-sans'].family} | `font-sans` | `--font-sans` |
| Mono | {fonts['font-mono'].family} | `font-mono` | `--font-mono` |

**Inter** comes from the poimandres `preset` registry item, installed by the
[getting-started command](/getting-started/introduction#install). The pinned setup
uses the equivalent preset code, `b1VlIttI`. On Next.js it loads through `next/font/google` as
`--font-sans`. Headings use the same family: the preset sets `--font-heading: var(--font-sans)`.

**Inconsolata** comes from the `font-mono` registry item, which `theme` depends on, so adding the
theme installs it:

<Code {...installCommands.theme} />

It is scoped to `code, kbd, samp, pre`: those elements use it without a class, and the rest of
the UI keeps Inter. In your own app code, add the `font-mono` utility to any other element that
should be monospace. Blocks never do: they inherit the font of the app they land in.

The specimens below render with this site's CSS, which may not load the same fonts as your
project. The table is rendered from `foundations.json`.

    <p className="font-sans text-base">The quick brown fox jumps over the lazy dog.</p>

  </div>

## Type scale

> [!NOTE]
> Inherited from Tailwind v4 defaults, not yet a pmndrs decision. See [Tailwind's font-size docs](https://tailwindcss.com/docs/font-size).

Each `text-*` utility sets a font size and its paired line height, from the `--text-*` and
`--text-*--line-height` theme variables. Pixels assume the browser's default 16px root. The
previews render with this site's CSS: its root is 17px, so they draw slightly larger than in
your project.

## Font weight

> [!NOTE]
> Inherited from Tailwind v4 defaults, not yet a pmndrs decision. See [Tailwind's font-weight docs](https://tailwindcss.com/docs/font-weight).

`font-*` sets `font-weight` from the `--font-weight-*` theme variable. Text is `font-normal`
unless a class says otherwise. Inter covers every step; Inconsolata starts at 200, so
`font-thin` on code renders at 200.

| Utility | Variable | Value | Preview |
| --- | --- | --- | --- |
| `font-thin` | `--font-weight-thin` | <code>{fontWeights['font-thin'].value}</code> | <span style={{ fontWeight: fontWeights['font-thin'].value }}>Aa</span> |
| `font-extralight` | `--font-weight-extralight` | <code>{fontWeights['font-extralight'].value}</code> | <span style={{ fontWeight: fontWeights['font-extralight'].value }}>Aa</span> |
| `font-light` | `--font-weight-light` | <code>{fontWeights['font-light'].value}</code> | <span style={{ fontWeight: fontWeights['font-light'].value }}>Aa</span> |
| `font-normal` | `--font-weight-normal` | <code>{fontWeights['font-normal'].value}</code> | <span style={{ fontWeight: fontWeights['font-normal'].value }}>Aa</span> |
| `font-medium` | `--font-weight-medium` | <code>{fontWeights['font-medium'].value}</code> | <span style={{ fontWeight: fontWeights['font-medium'].value }}>Aa</span> |
| `font-semibold` | `--font-weight-semibold` | <code>{fontWeights['font-semibold'].value}</code> | <span style={{ fontWeight: fontWeights['font-semibold'].value }}>Aa</span> |
| `font-bold` | `--font-weight-bold` | <code>{fontWeights['font-bold'].value}</code> | <span style={{ fontWeight: fontWeights['font-bold'].value }}>Aa</span> |
| `font-extrabold` | `--font-weight-extrabold` | <code>{fontWeights['font-extrabold'].value}</code> | <span style={{ fontWeight: fontWeights['font-extrabold'].value }}>Aa</span> |
| `font-black` | `--font-weight-black` | <code>{fontWeights['font-black'].value}</code> | <span style={{ fontWeight: fontWeights['font-black'].value }}>Aa</span> |
