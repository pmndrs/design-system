  Every pmndrs block and lib is a [shadcn registry](https://ui.shadcn.com/docs/registry) item,
  installed with the shadcn CLI straight from the GitHub repo that publishes it — no npm
  package, no registry server. This page lists them all, across repos.
</Intro>

## Pinning

The part after `#` is a git ref — a tag or a branch — and the CLI reads `registry.json` and
the item's files at that ref. Pin a tag: an address without one follows the repo's default
branch, and changes under you.

Refs are not inherited: each of an item's registry dependencies carries its own, which is why
they are listed below with theirs.

> [!NOTE]
> pmndrs/docs has no tagged release with a registry yet, so its blocks install from the `ds`
> branch, which moves. Their commands will pin a tag once there is one.

## Browse from the terminal

The CLI lists the same items, read live from each repo at the same refs:

```sh
npx shadcn@latest search pmndrs/design-system#v0.5.0 pmndrs/docs#ds
```

and `npx shadcn@latest view <address>` prints an item, files and all, before you add it.

## pmndrs/design-system

2 items, from [`registry.json`](https://github.com/pmndrs/design-system/blob/v0.5.0/registry.json) at `v0.5.0`.

### md3-base

The MD3 colour layer without any colours: the package's Tailwind plugin, its shadcn remap, and the pmndrs seed. Install this only if you compute the palette yourself — otherwise install `md3`, which supplies one.

```sh
npx shadcn@latest add pmndrs/design-system/md3-base#v0.5.0
```

Type `registry:lib` · registry dependencies: none

### md3

The pmndrs Material Design 3 colour layer. Additive to the stock shadcn tokens — blocks use `bg-primary` by default and reach for `bg-surface-dim` only where shadcn has no equivalent. Nothing to mount.

```sh
npx shadcn@latest add pmndrs/design-system/md3#v0.5.0
```

Type `registry:lib` · registry dependencies: `pmndrs/design-system/md3-base#v0.5.0`

## pmndrs/docs

2 items, from [`registry.json`](https://github.com/pmndrs/docs/blob/ds/registry.json) at `ds`.

### keypoints

A titled panel listing the main points an article covers — one bullet per `KeypointsItem`. Usually sits right after the intro.

```sh
npx shadcn@latest add pmndrs/docs/keypoints#ds
```

Type `registry:block` · registry dependencies: `pmndrs/design-system/md3#v0.4.0`

### color

Swatches of the theme's Material 3 color roles, as Material's scheme poster shows them. `Color` is a disc inline in text, or a cell with the role's name on it in the ink Material pairs with it; `ColorGroup` fuses cells into one rounded block, horizontal or vertical, nesting as rows. Takes any role in kebab-case (`primary`, `on-tertiary-fixed-variant`, a custom color), or any CSS color.

```sh
npx shadcn@latest add pmndrs/docs/color#ds
```

Type `registry:block` · registry dependencies: `pmndrs/design-system/md3#v0.4.0`
