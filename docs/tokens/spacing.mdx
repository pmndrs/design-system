<Intro>
  Every spacing utility is a multiple of one base unit, `--spacing`. A utility
  `n` is `n × 0.25rem`: `p-4` is `1rem`, `gap-2` is `0.5rem`.
</Intro>

> [!NOTE]
> Inherited from Tailwind v4 defaults, not yet a pmndrs decision. See [Tailwind's padding docs](https://tailwindcss.com/docs/padding).

## Base unit

<FoundationTable name="spacing.base" foundations={foundations} />

The same scale drives padding (`p-*`), margin (`m-*`), gaps (`gap-*`, `space-*`), sizes (`w-*`,
`h-*`, `size-*`, `min-*`, `max-*`), offsets (`inset-*`, `top-*`…) and translations
(`translate-*`). Any multiple works, not only the steps below: `p-13` is `3.25rem`. Prefix a
utility with `-` for a negative value (`-mt-2`), and use brackets for a one-off (`p-[5px]`).
