## Animated

Idle → complete, once, in 0.73 s. Under reduced motion, the complete mark shows without
moving.

<img src="logo_animated.svg" width="160" alt="The pmndrs logo, springing from idle to complete" />

<Badge href="https://github.com/pmndrs/design-system/raw/main/docs/assets/logo_animated.svg" label="download">SVG</Badge>

## Loading

Loops idle → each corner → idle, every 5.3 s. Under reduced motion, the shapes stay put and the
mark only fades gently, so it still reads as busy.

<img src="logo_loading.svg" width="160" alt="The pmndrs logo, looping as a loader" />

<Badge href="https://github.com/pmndrs/design-system/raw/main/docs/assets/logo_loading.svg" label="download">SVG</Badge>

## Usage

Drop the file in your app's `public/` and use it as an image. Both animations are CSS inside the SVG, so a plain `<img>` plays them,
and so does `next/image` with `unoptimized`:

```tsx
<img src="/logo_loading.svg" width={48} height={48} alt="Loading" />
```
