## External components

Expand the versioned reference in the sidebar for the supported registry blocks.
These stories run in their own preview with their own theme.

The sidebar only displays components supported by the DS, listed in
`registry/external.json`. Check the
[registry catalog](https://pmndrs.github.io/design-system/getting-started/introduction#registry-items)
for supported items and pinned installation versions.

Each composed Storybook is pinned to a published build from the catalog's release.
Some addons behave differently in composition; use the original Storybook when you
need its full tooling:
