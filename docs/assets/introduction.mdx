<Intro>
  The pmndrs logo, in four states. Install the four SVGs into your app with one command, or
  preview each one here and download the file you need.
</Intro>

```sh
npx shadcn@latest add pmndrs/design-system/pmndrs-logo#v0.5.0
```

That writes them to `public/pmndrs/` at the root of your project, under the names this page
gives them. The PNGs are downloads only: a registry carries text files.

Every file is 600×600 and paints its own black square background: there is no transparent
variant yet.

## Animated

Idle → complete, once, in 0.73 s. Under reduced motion, the complete mark shows without
moving.

<img src="logo_animated.svg" width="160" alt="The pmndrs logo, springing from idle to complete" />

<Badge href="https://github.com/pmndrs/design-system/raw/main/docs/assets/logo_animated.svg" label="download">SVG</Badge>

## Loading

Loops idle → each corner → idle, every 5.3 s. Under reduced motion, the shapes stay put and the
mark only fades gently, so it still reads as busy.

<img src="logo_loading.svg" width="160" alt="The pmndrs logo, looping as a loader" />

<Badge href="https://github.com/pmndrs/design-system/raw/main/docs/assets/logo_loading.svg" label="download">SVG</Badge>

## Usage

Installed, or dropped in your app's `public/pmndrs/` by hand, each file is an image URL. Both
animations are CSS inside the SVG, so a plain `<img>` plays them, and so does `next/image` with
`unoptimized`:

```tsx
<img src="/pmndrs/logo_loading.svg" width={48} height={48} alt="Loading" />
```
