## Registry items

Install code and assets from the
[pmndrs registry](https://pmndrs.github.io/design-system/r/registry.json)
or another [GitHub registry](https://ui.shadcn.com/docs/registry/github).

```sh
npx shadcn@latest search @pmndrs
npx shadcn@latest view @pmndrs/logo
npx shadcn@latest add @pmndrs/logo @pmndrs/figma-tokens
```

> [!NOTE]
> Listed in the [shadcn directory](https://ui.shadcn.com/docs/directory?q=pmndrs),
> `@pmndrs` works without registry configuration.

## Versioning

The hosted `/r/` URLs and `@pmndrs` follow `main`. To install a specific release,
use a GitHub address with a tag:

<Code {...installCommands.logo} />

Each dependency keeps its own ref. Installing from a branch preview does not
make its dependencies follow that branch.
