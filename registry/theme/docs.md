The default pmndrs theme. This item is an alias for `theme-lime`: it installs the Lime palette, `md3-base` and `font-mono` through that dependency and declares no colours of its own.

Install `@pmndrs/theme` to get or restore the default, or `@pmndrs/theme-<colour>` to select a named seed. See `theme-lime` for the palette and custom colour utilities. No provider or client JavaScript is needed.
