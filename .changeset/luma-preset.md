The poimandres shadcn preset moves from style `base-nova` to `base-luma`: the new code is `b5dwpqytk` (was `b5cR4Y50S`), every other preset value unchanged. `base-luma` is the style the pmndrs docs sites already run on, so a project initialised from the preset now matches them. The radius scale `base-luma` writes is the same as `base-nova`'s (`--radius: 0.625rem`, multiplicative steps); the Radius, Typography and Getting Started pages now name the new style and code.
