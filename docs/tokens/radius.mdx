<Intro>
  Every corner in a pmndrs project derives from one value, `--radius`. The `rounded-*` utilities
  are multiples of it, so changing that one value rescales every corner at once.
</Intro>

## Base

<FoundationTable name="radius.base" />

It comes from the poimandres shadcn preset (`b1VlIttI`, style `base-luma`, radius `default`),
applied by `npx shadcn@latest init @pmndrs/preset`.

## Scale

The preset's `base-luma` style derives the scale by multiplication: each step is `--radius`
times a factor. Values below are at a 16px root.

<FoundationTable name="radius.scale" />

The table is rendered from `foundations.json`: the previews below render this site's own radius scale, which
can differ slightly from what your project gets.
