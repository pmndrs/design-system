<Intro>
  No colour is picked by hand. A few seeds go in, and
  [Material Design 3](https://m3.material.io/styles/color/system/overview) computes every role
  from them, for light and dark alike. shadcn's tokens are then pointed at those roles.
</Intro>

Every poster below comes in both schemes: its Light / Dark tabs switch them all together,
whatever the scheme of this site.

## Seeds

Everything on this page derives from these, in
[`md3.ts`](https://github.com/pmndrs/design-system/blob/main/registry/md3-base/md3.ts):

## Poster

role, and on it the role meant to go on it. Every one is a Tailwind colour, `bg-<role>` /
`text-<role>`.

## shadcn tokens

shadcn's tokens keep their names: `bg-background`, `text-primary`, `border-border`… all work as
usual. Each one is pointed at an MD3 role, the same poster with shadcn's names on it:

<Tabs defaultValue="light" syncKey="scheme">
  <TabsList>
    <TabsTrigger value="light">Light</TabsTrigger>
    <TabsTrigger value="dark">Dark</TabsTrigger>
  </TabsList>
  {['light', 'dark'].map((scheme) => (
    <TabsContent key={scheme} value={scheme}>
      <div className="ds-palette my-8 rounded-lg bg-[var(--md-sys-color-surface)] p-4" data-scheme={scheme}>
        <div className="grid! grid-cols-[3fr_1fr] gap-2">
          <ColorGroup>
            <ColorGroup orientation="vertical">
              <Color role="primary" variant="cell">primary · ring</Color>
              <Color role="on-primary" variant="on">primary-foreground</Color>
            </ColorGroup>
            <ColorGroup orientation="vertical">
              <Color role="secondary-container" variant="cell">secondary · accent</Color>
              <Color role="on-secondary-container" variant="on">secondary-foreground · accent-foreground</Color>
            </ColorGroup>
          </ColorGroup>
          <ColorGroup orientation="vertical">
            <Color role="error" variant="cell">destructive</Color>
          </ColorGroup>
          <ColorGroup orientation="vertical">
            <ColorGroup>
              <Color role="surface" variant="cell">background</Color>
              <Color role="surface-container-low" variant="cell">card · sidebar</Color>
              <Color role="surface-container-high" variant="cell">popover</Color>
              <Color role="surface-container-highest" variant="cell">muted</Color>
            </ColorGroup>
            <ColorGroup>
              <Color role="on-surface" variant="on">foreground</Color>
              <Color role="on-surface-variant" variant="on">muted-foreground</Color>
              <Color role="outline" variant="on">input</Color>
              <Color role="outline-variant" variant="on">border</Color>
            </ColorGroup>
          </ColorGroup>
          <div />
          <ColorGroup>
            <Color role="primary-fixed" variant="cell">chart-1</Color>
            <Color role="secondary-fixed" variant="cell">chart-2</Color>
            <Color role="tertiary-fixed" variant="cell">chart-3</Color>
            <Color role="primary-fixed-dim" variant="cell">chart-4</Color>
            <Color role="secondary-fixed-dim" variant="cell">chart-5</Color>
          </ColorGroup>
        </div>
      </div>
    </TabsContent>
  ))}
</Tabs>

The `sidebar-*` tokens follow their counterparts: `sidebar-primary` is `primary`,
`sidebar-accent` is `accent`, `sidebar-border` is `border`, `sidebar-ring` is `ring`.

Everything shadcn has no name for is there too, under its MD3 name: `bg-surface-dim`,
`bg-tertiary-container`, `text-on-surface-variant`…

## Custom colours

Colours Material has no role for — a brand palette, status levels — are declared next to the
seeds, as `customColors`. Each one becomes four roles, `<name>`, `on-<name>`,
`<name>-container` and `on-<name>-container`, computed for light and dark like the others, plus
eleven shades, `<name>-50` … `<name>-950`. `blend` harmonizes it toward the `source` seed;
without it the colour stays true to its hex.

## Reseeding

The palette is computed, never written by hand: change the seeds in
[`md3.ts`](https://github.com/pmndrs/design-system/blob/main/registry/md3-base/md3.ts), run
`npm run build`, and every swatch on this page follows, with the baked CSS of the registry and
the [Figma tokens](https://github.com/pmndrs/design-system/tree/main/figma).

For a palette of your own, install `md3-base` instead of `md3` and emit the roles from your seeds:

```sh
npx shadcn@latest add pmndrs/design-system/md3-base#v0.4.0
```
